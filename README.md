> Bem-vindo ao repositório comunitário de legendas do projeto [One Pace BR](https://one-pace-br.pages.dev/).

## 📖 Sobre o Projeto

O **One Pace BR** é um hub unificado criado para facilitar o acesso do público brasileiro e demais falantes da língua portuguesa ao projeto One Pace. Centralizamos o conteúdo e as legendas em PT-BR em um só lugar, eliminando a necessidade de buscas em sites externos ou garimpo em trackers de torrent.

Este repositório existe para garantir a organização, versionamento e facilitar a manutenção de todas as legendas (arquivos `.srt` ou `.ass`) que alimentam o nosso hub e sincronizam perfeitamente com players locais e servidores de mídia (como Jellyfin e Plex).

---

## 🤝 Quero ajudar com as legendas!

Caso encontre erros de sincronia, erros de digitação ou note a ausência de legendas em episódios recém-lançados pelo One Pace, a sua contribuição é muito bem-vinda!

Toda a manutenção é feita através de **Pull Requests (PRs)** neste repositório. 

### ⚠️ Diretrizes de Tradução e Revisão

Para agilizar o processo de criação de novas legendas, você pode utilizar Inteligência Artificial (IA) ou ferramentas de tradução automática. **No entanto, a revisão manual é estritamente essencial.**

Ferramentas automáticas frequentemente se perdem na localização, no contexto específico da obra e nos jargões do universo de One Piece (ex: *Akuma no Mi*, *Haki*, nomes específicos de golpes e ilhas). Pedimos que Sempre revise o conteúdo assistindo a algumas cenas para garantir a fluidez e a fidelidade da tradução antes de enviar o seu Pull Request.

---

## 🛠️ Ferramentas e Fontes Recomendadas

Para iniciar ou facilitar a sua tradução, recomendamos o seguinte fluxo de trabalho:

### Editor de Legendas Recomendado
*   **[Subtitle Edit](https://www.nikse.dk/subtitleedit):** Excelente software open-source para tradução, ajuste de tempo (sync) e revisão em lote.

### Fontes para Legendas Base (Outros Idiomas)
Se você precisa de uma legenda base em Inglês (ou outro idioma) para traduzir para o PT-BR, busque nestas fontes confiáveis:
1.  [Anime Tosho](https://animetosho.org/)
2.  [One Pace Public Subtitles](https://github.com/OnePace/public-subtitles)

## 🚀 Como Contribuir (Passo a Passo)

1. Faça um **Fork** deste repositório.
2. Clone o seu fork para a sua máquina local: `git clone https://github.com/seu-usuario/repo-legendas.git`
3. Crie uma branch para a sua legenda: `git checkout -b add-legenda-elbaph-ep1`
4. Adicione o arquivo de legenda na pasta correspondente da saga/arco.
5. Faça o commit das suas alterações: `git commit -m 'feat: adiciona legenda PT-BR para Elbaph Ep 01'`
6. Faça o push para a sua branch: `git push origin add-legenda-elbaph-ep1`
7. Abra um **Pull Request** aqui no repositório original detalhando o que foi feito.
